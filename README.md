# David School Options

An installable web app (PWA) for comparing school options for David (age 12, Frisco, TX): homeschool, hybrid (for example 2 days at school and 3 at home), virtual public, private and public school. It also covers state, federal, county and private funding, IEP rights, social-skills supports and a homeschool planner.

- Facts come only from official sources. Each one links to its source and shows the date it was checked (Nov 18, 2026).
- No SSNs, student ID numbers or medical record numbers are collected.
- Data stays in this browser's localStorage. Optional Sync saves it to a private GitHub Gist ("David School Options Sync") using the owner's own token, entered on the Sync page.
- Works offline. Includes export and import backups and a dark mode.

This app is for information only. It isn't legal, financial or educational advice.
